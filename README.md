# **Markdown Cheat Sheet**

## **Headings**
# H1 Heading
## H2 Heading
### H3 Heading
#### H4 Heading
##### H5 Heading
###### H6 Heading

## **Emphasis**
*Italic* or _Italic_  
**Bold** or __Bold__  
***Bold and Italic*** or ___Bold and Italic___  

## **Lists**
### Unordered List
- Item 1
- Item 2
  - Sub-item 1
  - Sub-item 2
- Item 3

### Ordered List
1. Item 1
2. Item 2
   1. Sub-item 1
   2. Sub-item 2
3. Item 3

## **Links**
[Clickable Text](https://example.com)

## **Images**
![Alt Text](https://example.com/image.jpg)

## **Code**
### Inline Code
Use `code()` to display inline code.
